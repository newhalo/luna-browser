! HOW TO MAINTAIN
! - A site shows ads again: try "Update filter lists" in Settings first (ABPVN usually has the rule already).
! - Still there: add a rule in the matching section below, with a date and the affected site.
! - Re-check with tools/sitecheck (see docs/ADBLOCK.md), add a unit test if the rule has a new shape.
! - Rules for every site go in sections 1-3; rules for one site go in section 4.
!
